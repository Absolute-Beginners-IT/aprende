# Mapa de Infraestructura (página web)

`mapa-infraestructura.html` es el código de la base de conocimiento interactiva publicada en Claude.
Se publica como artifact de Claude: los datos (equipos, actuaciones, pruebas) se guardan en el
almacenamiento del artifact, no en este archivo. Abierto en local funciona en modo de prueba
(los cambios solo duran mientras la página está abierta).
